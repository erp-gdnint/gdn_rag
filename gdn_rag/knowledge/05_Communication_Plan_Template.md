Part 4. Milestone touchpoints

The table below maps the mandatory interaction points to the grant reporting schedule. These are fixed and cannot be skipped. The two-week rule applies to all submissions: the grantee shares a draft with the mentor at least two weeks before the GDN deadline, the mentor reviews and returns comments within one week, and the grantee finalises and submits to GDN in the final week. GDN will not process disbursements on reports that have not been reviewed and approved by the mentor.

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| Milestone | Approx. timing | What the grantee submits | What the mentor does |
| Kickoff and project plan review | Month 1 | Revised project plan, communication plan | Reviews and approves project plan, co-develops communication plan, submits brief report to GDN |
| Progress report (mid-term) | As per Annex II | Progress report (Annex III), FUS, activity documentation | Reviews and approves report before grantee submits to GDN, submits own brief progress report to GDN |
| Draft research paper / output | End of later quarter (ORD) | Draft manuscript or equivalent output | Provides written comments to grantee and GDN |
| Final report and closeout | End of implementation | Final report, FUS, dissemination plan, 500-word policy brief | Reviews and approves all final documents, advises on publication options, submits final assessment report to GDN |

Part 6. If something goes wrong

Agreeing on this before it is needed makes it much easier to use. The most common scenarios are (more detailed scenarios and other rare situations and what to do are available in the risk and escalation FAQ and guide [here](https://docs.google.com/document/d/13OSzwgoR_fX6tyv-8n9M63TC4QolI7A7/edit?usp=drive_link&ouid=116394735110013719331&rtpof=true&sd=true)): one party stops responding, a deadline is missed, or a disagreement arises about the project direction. Use the steps below as a starting point and adapt if needed.

|  |  |  |
| :-: | :-: | :-: |
| Step | Situation | Action |
| 1 | Communication has gone quiet for more than two weeks with no explanation | The other party sends a direct message on the agreed channel. If no response within five working days, move to Step 2. |
| 2 | No response after Step 1, or a disagreement cannot be resolved between mentor and grantee | Contact GDN directly: jcosta@gdn.int, copying awards@gdn.int. GDN will facilitate a three-way conversation. |
| 3 | A serious issue arises: potential misuse of funds, safety concern, or significant change to the project | Contact GDN immediately, regardless of the stage of the above steps. |

If there is a concern you are not comfortable raising with the other party directly, contact João Costa at GDN. All conversations with GDN are handled with discretion.
